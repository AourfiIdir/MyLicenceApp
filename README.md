# SignWise 🚗

SignWise is a mobile app that makes preparing for your driver's license exam fun and effective.
With a bold comic-book design, it turns road rules and driving regulations into a game you actually enjoy playing.

## ✨ Features

- 📚 **Learn** — browse study cards by category and flip through the rules
- ⚡ **Quizzes** — test yourself with category-based quizzes and earn points
- ❌ **Mistake tracking** — every wrong answer is saved so you can review and re-practice exactly what you got wrong
- 🗂️ **Custom lists** — build your own revision lists and study them at your own pace
- 📊 **Progress & profile** — track your stats and see how far you've come
- 🔐 **Secure auth** — email/password + Google sign-in with JWT & refresh tokens
- 🎨 **Comic-book UI** — a bold, fun design that keeps learning light

## 🛠️ Tech Stack

- **React Native 0.81 + Expo SDK 54** with Expo Router (file-based navigation)
- **TypeScript** throughout
- **Context API** for auth state + secure token storage (SecureStore/AsyncStorage)
- **Jest + React Native Testing Library** for tests
- **EAS Build** ready for iOS & Android

## 🚀 Getting Started

```bash
npm install
npm start
```

> Set up your `.env` from `.env.example` (Google OAuth client ID and backend URL) before running.

## 🧪 Tests

```bash
npm run lint   # lint
npx jest       # run tests
```
```
